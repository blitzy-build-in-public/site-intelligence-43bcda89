Bundled map data licence notice
===============================

File covered: src/assets/geo/countries-110m.json

1. What the file is

countries-110m.json holds the Natural Earth 1:110m admin-0 country boundaries as
TopoJSON, roughly 105 KB (107,761 bytes). It is committed in the repository and
compiled into the application bundle, where it supplies the geometry drawn by the
FileMap canvas map lens. The TopoJSON topology carries two objects, "countries"
and "land".

2. The data: Natural Earth 4.1.0, public domain

The geometry is Natural Earth 4.1.0 at the 1:110m scale. Natural Earth data is in
the public domain: no permission is needed to use it, and no credit is required
for the data itself, although crediting "Natural Earth" is customary. The
upstream terms of use are published at
https://www.naturalearthdata.com/about/terms-of-use/

3. The packaging: the world-atlas 2.x distribution, ISC licence

The file was taken unchanged from the world-atlas 2.0.2 distribution, which
repackages Natural Earth as ready-built TopoJSON. The copy committed here is
byte-identical to that distribution's own countries-110m.json, so no conversion
or re-projection was applied. That distribution is a separate work licensed under
the ISC licence, which is reproduced in full below for the packaging this file
came with. Project home: https://github.com/topojson/world-atlas

4. Not a dependency of this project

world-atlas is not declared in package.json and does not appear in
package-lock.json. The geometry is committed into the repository beside this
notice, so it travels with the application bundle and neither a build step, a
test step nor the running application reaches any host for it. Nothing imports
this notice: it is inert text that keeps the required attribution in the folder
that holds the data.
